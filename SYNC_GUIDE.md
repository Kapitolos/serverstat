# How to Sync Data Between Desktop and Mobile

ShiftStats uses **localStorage** which stores data in your browser. To use the app on both desktop and mobile, you'll sync data using JSON export/import files.

## Workflow

### On Desktop (GitHub Pages):
1. **Add your shift** using the form
2. **Click "📥 Export to Phone"** button
3. **Save the JSON file** to your computer
4. **Transfer the file to your phone** (email, cloud storage, USB, etc.)

### On Mobile:
1. **Open ShiftStats** on your phone's browser
2. **Click "📤 Import from Phone"** button
3. **Select the JSON file** you transferred
4. **Your data is now loaded!**
5. **Add new shifts** on mobile
6. **Export again** when done
7. **Transfer back to desktop** and import

## Step-by-Step Example

### First Time Setup:
1. **Desktop**: Add some shifts, export JSON file
2. **Transfer**: Email the file to yourself or use cloud storage
3. **Mobile**: Download the file, open ShiftStats, import it
4. **Mobile**: Now you can add shifts on your phone!

### Daily Workflow:
1. **End of shift on mobile**: Add shift → Export JSON → Save to phone
2. **At home on desktop**: Import JSON → All shifts synced!
3. **Next day**: Export from desktop → Import on mobile → Ready to go!

## Tips

- **Export regularly** - Don't lose your data!
- **Keep backups** - Save multiple export files
- **Name your files** - Use dates like `shiftStats_2024-01-15.json`
- **The export includes everything**: shifts, employees, settings

## File Transfer Methods

- **Email**: Email the file to yourself
- **Cloud Storage**: Google Drive, Dropbox, iCloud
- **USB Cable**: Direct transfer
- **AirDrop** (iOS): Quick wireless transfer
- **QR Code**: Some apps can generate QR codes for files

---

**Remember**: The JSON file contains ALL your data. Keep it safe and private!
